# Thesis Writing & Polishing Skill

面向HIT中文学位论文的 AI 辅助写作、学术润色与 LaTeX 排版 Skill。

## 项目简介

本项目致力于将 AI 辅助学术写作能力与规范化学位论文排版相结合，为研究生提供更加高效、规范的论文写作与修改支持。

本 Skill 在开发过程中，借鉴了开源项目 [graduate-thesis-polish-and-write-skill](https://github.com/lmcggg/graduate-thesis-polish-and-write-skill) 中的学术写作规范，特别是 [patterns-math.md](https://github.com/lmcggg/graduate-thesis-polish-and-write-skill/blob/main/thesis-polish/patterns-math.md) 所提出的数学公式叙述、推导逻辑、定理证明及学术表达规范。

同时，本项目结合 [HIThesis](https://github.com/hithesis/hithesis) 提供的哈尔滨工业大学学位论文 LaTeX 模板及排版体系，探索将学术内容生成、语言润色、数学表达与论文格式规范有机结合，形成面向学位论文写作的辅助工作流。

## 设计理念

本 Skill 主要围绕以下目标展开：

- **学术表达规范化**：借鉴已有学术写作经验，改善论文语言表达、逻辑衔接与学术规范性。
- **数学内容严谨化**：关注公式引入、符号定义、数学推导、定理证明及跨章节符号一致性。
- **LaTeX 排版标准化**：结合 HIThesis 模板体系，使论文内容组织与学位论文排版要求相衔接。
- **AI 辅助写作一体化**：探索将论文写作、审校、润色与 LaTeX 文档维护整合至统一工作流。
